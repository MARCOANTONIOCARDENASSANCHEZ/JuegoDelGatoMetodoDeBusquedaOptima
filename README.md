# JuegoDelGatoMetodoDeBusquedaOptima
Tres Golpes es una versión digital del juego clásico tres en raya. El jugador compite contra una inteligencia artificial que puede utilizar el algoritmo Minimax para analizar todas las continuaciones posibles y seleccionar una jugada óptima. El proyecto cumple con la actividad porque incluye: - Un juego clásico completamente funcional.
